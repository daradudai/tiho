Privacy policy

Applies to the Tiho browser extension 0.1 and to this website. Last updated: 11 October 2026.

Short version: Tiho filters live chat on your own device. It has no server, no account, no analytics and no telemetry. Chat messages never leave your computer. This page explains exactly what the extension reads, stores and sends.

What Tiho reads

  • Chat on YouTube, Twitch and Kick. A content script reads each new chat message on those sites: author name, badges (to know who is a moderator or VIP), message text, emotes and whether it is a paid message. That is what gets classified.
  • Your own username, where possible. On Twitch and YouTube, so that messages mentioning you are never hidden. It is used in the page only and is never stored or sent.
  • The chat's theme (light or dark), so Tiho's bar matches the site.
  • The addresses of the frames in open YouTube, Twitch and Kick tabs, once, when Tiho is installed or updated, to find chats that are already open and start Tiho in them without a reload.

Tiho does not read anything else on those pages and does not run on any other website.

Where the work happens

Every message is classified inside your browser by an AI model that ships with the extension, running on your graphics card (WebGPU) or processor (WebAssembly). No code or model is loaded from the internet, and no message text is sent anywhere.

What Tiho sends over the network

No chat text leaves your computer. The extension has no server to talk to. The only network traffic it can make involves the optional Tiho Engine:

  • Tiho Engine, only if you turn it on. It is off by default, and while it is off the extension sends it nothing. When you turn it on, the extension sends the text of chat messages (with the platform name), your custom filter questions and any stream context you typed to the Engine address in your settings. By default that is http://127.0.0.1:7377, which is your own computer, so none of it leaves your machine. If you change the address to another computer, the data goes there instead, so only do that for a machine you control.

Separately, when the side panel cannot get the Engine's status from the extension itself, it may ask the Engine address directly whether the Engine is running. That request contains no chat text and, with the default address, never leaves your computer.

The 127.0.0.1 and localhost entries in the extension's permissions exist only for Tiho Engine.

Tiho Engine

The optional Engine is a separate app that runs on your computer. It listens only on 127.0.0.1, accepts requests only from the browser extension and from localhost, keeps message text only in memory and never logs it. On first start it downloads its AI model and runtime from Hugging Face and GitHub.

What we never do

  • We do not collect, sell or share your data. We don't have any.
  • We do not use analytics, ads, cookies or tracking in the extension or on this website.
  • We do not transfer data to third parties or use it for anything unrelated to filtering your chat.

Training data

The model was trained on public live-chat messages collected without an account, together with permissively licensed public datasets. Some message texts (without author names) were labelled by AI annotators. Raw chat logs are kept privately, used only to build training data, and never published or shared; only the trained model is distributed.

This website

tiho.chat is a static website. It sets no cookies and runs no analytics or third-party scripts. It is served by Cloudflare, which, like any web host, processes your IP address and basic request data to deliver the pages and protect against abuse. If you email us, we use your address only to reply or to send the one launch email you asked for.
